# DownloadAny 网页发起流媒体下载

目标：从 DownloadAny 网页粘贴链接，由网页发起播放页识别，复用已有本地 HLS 合并与 MP4 保存。普通 MP4 继续使用已有网页解析。

- 纯网页不能读取跨域播放页的媒体资源；画中画也不会授予该权限。选择新标签页 + 已安装的本地扩展，由扩展仅在用户发起的播放标签页检测。
- 网页和扩展的桥仅在明确列出的 DownloadAny 站点启用。高途已知回放链接与直接 HLS/DASH 清单在本地分流，不经 Worker；其他页面无法静态解析时提供「在播放页识别」。
- 扩展管理页在必要时请求目标播放站点权限，打开原网页并有限时轮询；不模拟登录、不自动操作播放按钮、不扫描其他标签页。单个 HLS 结果自动生成 MP4，多结果由用户选，最后由浏览器保存。DASH 仍只识别。
- 用合成 HLS 检查真实网页桥、窗口切换、识别、合并和文件保存。实际高途回放另行验收。保留本地 Git Flow 和现有部署边界。
