# DownloadAny v0.3.2-beta.1

首个 GitHub Beta。下载附件 **DownloadAny-0.3.2-beta.1.zip**，解压后按[安装指南](https://downloadany.tufei-fly.workers.dev/install)在桌面 Edge 或 Chrome 的扩展管理页以开发者模式加载。请选择含 `manifest.json` 的文件夹，随后返回 [DownloadAny 试用站](https://downloadany.tufei-fly.workers.dev) 刷新页面。不要下载 GitHub 自动生成的 Source code ZIP 来安装。

- 识别播放器加载的 MP4，支持可读取的未加密 HLS 回放。
- 媒体在本机处理。请只保存有权下载的内容。
- GitHub 版本为 `v0.3.2-beta.1`；浏览器显示的扩展版本为 `0.3.2`。
- 商店入口会在对应商店发布后加入安装指南，GitHub Beta 下载仍会保留。
