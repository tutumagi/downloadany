MANUAL SETUP

四步安装 Beta

  1. 解压下载的 ZIP

    保留解压后的文件夹，确认里面可以直接看到 manifest.json。

  2. 打开浏览器的扩展管理页

    复制对应地址，粘贴到浏览器地址栏打开。

    Edgeedge://extensions
    Chromechrome://extensions

  3. 开启开发者模式并加载扩展

    点击「加载解压缩的扩展」或「加载已解压的扩展程序」，选择包含 manifest.json 的文件夹。安装后不要删除该文件夹。

  4. 回到 DownloadAny，刷新再试

    粘贴视频网址，按页面提示操作。以后改用商店版时，先停用开发者模式安装的副本，避免两个版本同时处理。
